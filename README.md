# Mini loja virtual

Exercício JavaScript com vitrine de produtos e carrinho gerado no navegador. Não inclui pagamento ou backend.

## Tecnologias

- HTML
- CSS
- JavaScript

## Funcionalidades e utilização

Clique nos produtos para adicioná-los ao carrinho e acompanhar as quantidades.

## Como executar

```bash
git clone https://github.com/EuGeanCarlos/Mini-Loja-vitual.git
cd Mini-Loja-vitual
python -m http.server 8000 --directory "minilojavirtual"
```

Requer Python 3 para o servidor local. Abra http://localhost:8000.
